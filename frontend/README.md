# frontend — หน้าเว็บ Guru IT Service Desk

หน้าเว็บคือแอปเดิมใน `public/` (`index.html`, `js/`, `css/`, `img/`) ต่อฐานข้อมูลจริงผ่าน backend
Next.js 16 ทำหน้าที่เปิดไฟล์เหล่านี้ และส่งคำขอ `/api/*` ต่อไปที่ backend พอร์ต 4000 (ดู `next.config.mjs`)

## รัน

ต้องเปิด backend ที่พอร์ต 4000 ก่อน (ดู `../backend/README.md`)

```
npm install
npm run build
npm run start    # ที่ http://localhost:3000
```

## ไฟล์ใน public/js

- `data.js` — ค่าคงที่ (สถานะ หมวดงาน บทบาท) และข้อมูลส่วนที่ยังเก็บในเครื่อง
- `api.js` — เรียก backend: เข้าสู่ระบบ โหลดข้อมูลที่ผู้ใช้มีสิทธิ์เห็น (`/api/state`) และส่งทุกการแก้ไข
- `permissions.js` — กติกาสิทธิ์ฝั่งหน้าเว็บ (ซ่อนปุ่ม) · server ตรวจซ้ำทุกครั้งใน `backend/rules.js`
- `i18n.js` — ภาษาไทย / อังกฤษ
- `app.js` — หน้าจอทั้งหมด

## ส่วนที่ต่อฐานข้อมูลแล้ว

เข้าสู่ระบบด้วยรหัสผ่าน · งาน (เปิดงาน มอบหมาย เปลี่ยนสถานะ ใบรายงาน เซ็นรับ ให้คะแนน ส่งกลับแก้ไข ความเห็น work log)
· ผู้ใช้และสิทธิ์ · ทีมช่าง · พาร์ทเนอร์และสถานที่ · รายงานผลงาน · บันทึกตรวจสอบ

## ยังเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น (ยังไม่แชร์ข้ามเครื่อง)

โปรเจกต์ · ภารกิจ/GPS · การแจ้งเตือน · โน้ตส่วนตัว
ปิดไว้ก่อนจนกว่าจะต่อฐานข้อมูล: แนบรูป · สมัครผ่านลิงก์ชวนของตัวแทนบริษัท
